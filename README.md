# CLICK – Cyber Security Lab Practicals

This **public repository** contains 16 practical code sheets prepared from the Cyber Security Lab practical-answer PDF.

## Start here

Open **[PRACTICALS_INDEX.md](./PRACTICALS_INDEX.md)** to see all 16 practicals and open each code sheet.

Every practical page lists the required file names and shows the code in readable code blocks. Copy each block into the named file to run the practical.

## Offline access

When internet is available, clone or download this repository and keep a local copy on your laptop or USB drive. You can then read the code sheets offline.

Educational demonstrations only. Run code locally or on systems where you have permission.
