# Cyber Security Lab Practicals

This repository contains 16 unique practical programs prepared from the lab answer compilation.

See folders `01` through `16`. Repeated questions are combined. See `requirements.txt` for Python dependencies.

## Run locally
- HTML: open the relevant `.html` file in a browser.
- Python: run `python filename.py` from the corresponding folder.
- Flask: install requirements with `python -m pip install -r requirements.txt`, then run the folder's `app.py`.

Educational demonstrations only. Run locally or on systems where you have permission.
